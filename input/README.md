# 개별 입력 사진

images에는 기존 예제 사진 20장을 유지합니다. 새 사진도 이곳에 넣을 수 있습니다.

- 기존 예제로 실행: main.py --samples
- 한 장만 실행: main.py --input input/images/beagle.jpg
- 수업용 Oxford 원본 데이터셋은 이 폴더가 아닌 datasets/oxford-iiit-pet에 둡니다.

out-of-scope 폴더와 관련 골든 리트리버 사진은 제거했습니다. 기본 입력 사진 20장은 보존했습니다. 출처·라이선스는 [기록](../data/smoke-test/SOURCES.md)에 있습니다.
