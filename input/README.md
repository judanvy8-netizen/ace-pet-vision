# 입력 사진

- `images/`: 기본 실행 대상. 현재 출처를 기록한 개·고양이 사진 20장이 들어 있습니다. 새 사진도 이 폴더에 넣습니다.
- `out-of-scope/`: 지원 범위 밖 사례를 별도로 보관합니다. 기본 실행 대상에 포함하지 않습니다.

사진의 품종·출처·저자·라이선스는 [data/smoke-test](../data/smoke-test/SOURCES.md)에 있습니다. 범위 밖 사진의 출처는 [data/out-of-scope](../data/out-of-scope/SOURCES.md)에 있습니다.

지원 확장자: JPG, JPEG, PNG, BMP, WEBP, TIF, TIFF. 원본을 보존하고 처리 결과는 `output/`에 저장합니다.
