# 실행 코드

- main.py: 기본 Oxford 데이터셋 실행. --samples로 기존 예제 실행.
- pet_model.py: 검증된 모델 다운로드, YOLO 탐지, 크롭과 37품종 분류.
- oxford_data.py: annotations/test.txt 또는 trainval.txt를 읽고 정답 비교.
- examples/: 데이터셋 확인, YOLO 탐지, 품종 분류의 짧은 예제 3개.

IntelliJ에서 해당 Python 파일을 우클릭하고 Run을 선택하세요. 프로젝트 SDK는 .venv/Scripts/python.exe를 사용합니다. 상세 옵션과 데이터셋 위치는 루트 README를 참고하세요.
