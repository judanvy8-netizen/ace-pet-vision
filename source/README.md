# Python 코드

IntelliJ에서 `main.py`를 우클릭하고 **Run 'main'**을 실행하세요. 프로젝트 SDK는 루트의 `.venv/Scripts/python.exe`를 선택합니다.

현재 main.py는 기본 입력 폴더 `input/images/`의 사진 목록과 프로젝트 경로를 출력하는 시작 파일입니다. 모델 추론이나 결과 저장을 구현한 것으로 표시하지 않습니다.

앞으로 탐지, 크롭·품종 분류, 시각화·저장, 정답표 비교 코드를 이 폴더에 추가하고 main.py에서 연결합니다. 현재 단계에서는 사용하지 않는 빈 모듈을 추가하지 않습니다.

프로젝트 루트의 터미널에서도 실행할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe source\main.py
```
