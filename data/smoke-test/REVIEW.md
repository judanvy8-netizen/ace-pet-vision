# 사진 수집·검토 기록

2026-10-27

작업 요청 요약: 기존 사진 오류를 검토하고, CC0/퍼블릭 도메인 사진을 추가하여 지원 품종 입력 확인용 20장을 준비하고 GitHub에 반영한다. README는 수정하지 않는다.

변경: 지원 품종 사진 16장 추가, 기존 4장 보존, 지원 목록에 없는 골든 리트리버 원본과 기록을 data/out-of-scope로 이동. 17열 CSV 형식 유지.

검사: 원본 설명과 라이선스 확인, 파일 디코딩·크기·SHA-256 대조, 파일-CSV 일대일 대응, 해시 중복·dHash 유사 후보 검색 및 육안 검토. HTTP 429가 발생한 원본은 사이트가 안내하는 공식 500/960px 축소본을 사용했다. 로컬에서 사진을 자르거나 생성하지 않았다.

기존 5장의 해시와 기록은 일치했다. 골든 리트리버를 지원 품종에 포함한 범위 오류를 수정했다. 페르시안의 다소 흐린 품질은 주의사항으로 남겼다.

미실행: 모델 실행, 정확도 평가, 모델 학습 데이터 중복 확인. 요청 기록에 후보 모델 식별자가 없어 특정 모델의 라벨·라이선스 검증은 하지 않았다.
