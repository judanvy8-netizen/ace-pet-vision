# 반려동물 품종 입력 확인용 사진 20장

고양이 10장·개 10장, 서로 다른 20품종입니다. 기존 지원 품종 4장을 보존하고 16장을 추가했습니다. 골든 리트리버는 [별도 보관](../out-of-scope/SOURCES.md)했습니다.

## 수집 기준과 한계

- 확인일: 2026-10-27. 개별 Commons 파일 페이지의 이미지 라이선스가 CC0 또는 저작권자 퍼블릭 도메인 공개인 자료만 채택했습니다. 페이지 하단 메타데이터 CC0 문구는 근거로 쓰지 않았습니다.
- 품종은 원본 설명에 근거합니다. Cinnamon은 원본이 명시한 개체 이름을 NHGRI 자료의 품종 설명과 대조했습니다. 출처의 표기는 혈통의 독립 검증이 아닙니다.
- 실제 파일을 열어 확인했습니다. 사람·워터마크가 보이는 후보와 여러 동물이 겹친 후보는 제외했습니다. 사진의 원본/공식 축소본 여부는 metadata.csv의 modifications에, 실제 다운로드 주소는 photo-review.json에 기록했습니다.
- 모델 추론·속도·정확도는 실행하지 않았습니다. 모델 학습 데이터와의 중복도 미확인입니다. 20장으로 37품종 전체의 성능을 검증했다고 주장할 수 없습니다.
- 지원 품종 범위 근거: [Oxford 공식 목록](https://www.robots.ox.ac.uk/~vgg/data/pets/). 모델 자체의 출력 라벨 일치는 모델 선정 후 별도 확인해야 합니다.

## 품질 주의사항

- persian: 기존 사진. 다소 흐림. 입력 확인용으로 유지.
- ragdoll: 얼굴 근접 촬영, 부드러운 초점.
- british_shorthair: 흑백 사진.
- sphynx: 얼굴이 아래를 향하는 전신 자세.
- chihuahua: 가로로 긴 근접 촬영. 축소본 500x231.
- samoyed: 하체가 통나무에 가려짐.
- maine_coon: 측면 얼굴 촬영.
- basset_hound: 저해상도 축소본이지만 한 마리 식별 가능.

Cinnamon 품종 보조 근거: [NHGRI 강의 자료 PDF 47쪽, 슬라이드 93](https://www.genome.gov/Pages/Research/IntramuralResearch/DIRCalendar/CurrentTopicsinGenomeAnalysis2006/CourseHandouts/CTGA2006Lec10Grey.pdf#page=47).
