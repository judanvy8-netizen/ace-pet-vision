## 1. 무엇을 만들기로 했나?

교사 원본 과제는 사진 속 **개/고양이 탐지·개수 계산·박스 표시·CSV 저장**이며, Python 3.11·Windows CPU·YOLO11n 사용이 기본입니다. 이후 교사의 **구두 추가 지시**에 따라 단순 개·고양이 구별을 넘어 **37개 품종 분류**를 필수 확장 기능으로 채택했습니다. 원본 Markdown에 품종 분류가 없는 것은 이 때문입니다.

**범위:** 우선 사진 파일 입력 → 사진 속 개·고양이 위치 찾기 → 영역별 37품종 후보 추론 → 결과 이미지·CSV 저장. 카메라·GUI는 후순위. Oxford-IIIT Pet 37품종(고양이 12, 개 25) 범위 밖인 골든 리트리버는 지원 품종이라고 주장하지 않습니다.

## 2. 지금 코드가 동작하는 구조

| 순서 | 주요 파일·함수 | 하는 일 / 사용 이유 |
|---|---|---|
| 1 | `source/main.py`, `shared/common.py:image_files`, `read_image` | 입력 폴더 사진을 순서대로 읽음. 없는 경로·손상 이미지 오류 구분 |
| 2 | `shared/common.py:yolo` | YOLO11n으로 cat(15), dog(16) 박스 탐지 |
| 3 | `shared/common.py:yolo_rescue` | 기본 탐지 0마리면 YOLO11s를 불러 재검사. 모든 사진에서 무거운 모델을 돌리지 않음 |
| 4 | `source/main.py --deep-rescue` | **선택사항:** 재검사 실패 시 1280px·TTA(`augment=True`)로 추가 탐지 시도. CPU에서 느리며 성공은 보장하지 않음 |
| 5 | `shared/common.py:classify_pets` + `shared/pet_model.py:BreedClassifier` | 검출한 동물 영역을 크롭하고 ResNet50으로 37품종 후보를 판별 |
| 6 | `shared/common.py:deduplicate_pets` | 전신/얼굴이 중복 검출돼 한 마리를 두 마리로 세는 문제 완화 |
| 7 | `shared/visualizer.py:annotate` | 박스·후보 품종·점수·마릿수를 결과 이미지에 표시 |
| 8 | `source/main.py`, `shared/common.py:save_csv` | `outputs/pet_counts.csv`, `pet_breeds.csv`, 처리 이미지를 원본과 별도 저장 |
| 9 | `shared/common.py:read_photo_sources` | `data/metadata.csv`의 `source_page`를 `pet_counts.csv` **`source_url`** 열에 기록 |
| 별도 | `--single-pet-review` | **사람이 사진에 동물 1마리가 있다고 확인한 경우에만** 전체 이미지 ResNet50 추정. YOLO 객체 탐지가 아니므로 **`review_only`**로 표시 |

## 4. 기술적 선택의 근거

1. **탐지와 품종 분류를 분리:** 사진 하나의 ResNet 품종 분류만으로는 여러 개체 위치·개수를 결정할 수 없습니다. YOLO 박스를 잘라 품종 모델에 전달합니다.
2. **중복 박스 병합:** 얼굴/몸통이 각각 별도 박스로 나오는 사례가 발생해 교집합/합집합 비율(IoU)과 작은 박스 포함률을 확인합니다. 실제로 동물이 서로 겹친 사진에서는 오병합 가능성이 있으므로 사람 검증이 필요합니다.
3. **미탐일 때만 무거운 검사:** YOLO11s와 TTA를 항상 쓰면 구형 Windows CPU에서 느려집니다. 검출 실패 경우에만 추가 실행합니다.
4. **닫힌 37품종 분류의 한계:** ResNet은 37개 중 후보를 강제로 고르므로, 지원 밖 품종 또는 동물이 없는 사진에서도 틀린 답을 낼 수 있습니다. 전체 이미지 분류는 반드시 `review_only`로 표시해 탐지 성공률에 포함하지 않습니다.
5. **사진 출처 열:** 출처를 결과와 함께 표시해 자료 제공자·사용 권한을 추적할 수 있도록 합니다. 출처가 없는 사진은 임의로 채우지 않습니다.

## 5. 검증 결과·남은 과제

- **모의 단위/통합 테스트:** 기존 10개에 출처 매핑·고해상도 재탐지·검토 전용 품종 분류 테스트를 추가해 **13개 통과**. 가짜 탐지·분류 모델을 사용했으므로 **실제 37품종 정확도 수치가 아님**.
- **사용자 확인 결과:** 05·07번 중복 문제 해결. 16·19번 기본/YOLO11s의 0마리 문제 여전함.
- **다음 실험:** 16·19번을 `--deep-rescue`로 다시 실행하고, 여전히 실패하면 `--single-pet-review`로 분류 후보만 확인. `review_only`는 '동물 위치 검출 성공'으로 기록하지 않음.
- **평가 자료:** `data/ground_truth.csv`의 20장 실제 개수, `test_cases.csv`의 관찰 결과, 동물 없음·혼합/가림 사례, 실패 사례 3개 이유 및 조건을 **사람이 확인하여 기록**해야 함.
- **발표 윤리:** 조장이 통합 구현한 코드라도 팀원별로 실제로 맡아 설명·수정·테스트한 내용을 구별해 제출합니다.

## 6. 실제 실행 예시

```powershell
# 코드 최신화
 git pull --ff-only
# 기존 이미지 20장 기본 처리
 .\run.bat --limit 0
# 16번 미탐지 고해상도·TTA 확인
 .\run.bat --input data/images/16_dog_samoyed.jpg --deep-rescue --output outputs/check_16
# 사람의 '사진 안에 동물 한 마리' 확인이 전제된 품종 검토 모드
 .\run.bat --input data/images/19_cat_sphynx.jpg --single-pet-review --output outputs/review_19
```

**참고:** 같은 `--output` 경로로 재실행하면 CSV가 갱신됩니다. 실험을 비교하려면 출력 폴더를 분리하세요.
